# DPO / TRO：有限投票下的偏好学习实验

研究目标：每个回答对只有少量、不同数量的投票时，根据逐题后验可信程度分配经验损失和鲁棒损失，检验训练后的生成表现能否更接近 oracle soft DPO。

| [实验状态与执行回传](EXPERIMENT_STATUS.md) | 本轮配置、任务进度、实际参数及结果链接 | 实验执行者 |

**当前版本：2026-11-10-v6.6-posterior-confidence。方案待实现与验证。**

可信权重为固定 Beta 先验下的后验概率：

$$
\lambda_i=\Pr\left(\left|p_i-\frac{K_i}{N_i}\right|\le\varepsilon\mid N_i,K_i\right).
$$

经验标签为 $K_i/N_i$；所有题共用一个 DRO 半径 $\rho$。开发集搜索全局 $\varepsilon$ 和 $\rho$，先验单独固定并报告。实验中 $0<\varepsilon\le0.1$，首轮建议网格为 $\{0.025,0.05,0.1\}$。

首轮半径网格已设定：KL 为 **0.005、0.05、0.1、0.3**；补充 $W_1$ 为 **0.01、0.05、0.15、0.3**。两种集合分别在开发集选参；不要求先做区间宽度匹配。$W_1$ 的 0.3 是鲁棒半径，不改变 $\varepsilon\le0.1$ 的限制。

主实验的 $N_i=1,3,5$ 按题目数量固定为 **4:3:3**：2,000 对分别分配 800、600、600 对，总计 5,600 票、平均每题 2.8 票；随机分配人数，同一重复内所有方法共享数据，外层每题仍等权。

实验包含两部分：少量异质投票下的六组方法比较（含后验均值 soft DPO），以及 $N=1,5,11,51,101$ 时 soft DPO 向 oracle 表现接近的检验。训练长度为 2048 tokens，主评测指标为平均 RM 奖励和逐题 oracle 短缺。开发选参每题生成 10 条，最终确认与人数增长评测统一 40 条。

**执行优先级**：P0 先完成可信度精确枚举诊断、后验均值 soft DPO 核心对照及 10/20/40 生成稳定性检查；P1 完成 KL 主实验、平均/打乱权重对照和人数增长；P2 再运行 W1 与其他敏感性补充。初始策略只做评测。具体步骤、验收标准、产物文件名及预算见纲要第 1.1、4.5、5、8.1 节。

## 如何协作

1. 框架负责人维护实验纲要，明确公式、参数范围和评测规则。
2. 实验执行者在状态表登记冻结配置与纲要 commit，按阶段实施。
3. 每阶段回填实际参数、指标、日志与产物，分别标记训练、生成、评分和分析状态。
4. 后续直接修改这两个固定文档，每次运行引用其实际采用的版本。
